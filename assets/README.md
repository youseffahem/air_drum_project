# assets/

Binary assets loaded from disk at runtime (docs/environment.md §7: no network at runtime). Created by Phase 03 (ADR-0014); Phase 04 adds `samples/` (drum samples + licences).

- `models/manifest.json` — every model file with `asset_id`, file name, source URL (versioned, never `latest`), SHA-256, size, licence and the library version that pinned it. **Always tracked.**
- `models/hand_landmarker.task` — MediaPipe Hand Landmarker (float16, v1, Apache-2.0), 7.8 MB, fetched once by `python scripts/fetch_hand_landmarker_model.py`; `--verify` re-hashes offline. **MANIFEST-ONLY** (owner decision, Phase 03 gate C-03-5): the binary is git-ignored (`assets/models/*.task`); after a fresh checkout run the fetch script once. The loader (`spacedrums.hands.model_asset`) refuses a file whose hash differs from the manifest.
- `samples/recorded-manifest.json` — hash-pinned, public-domain TR-505 electronic drum-machine bank (four-pad kit and non-demo modes; not acoustic recordings). The WAV binaries under `samples/recorded/` are git-ignored and can be restored with `python scripts/fetch_drum_samples.py`; `--verify` performs an offline hash check.
- `samples/acoustic-manifest.json` — hash-pinned **acoustic** Salamander Drumkit bank (genuine overhead-microphone recordings, CC BY-SA 3.0, Alexander Holm) played by the seven-piece `--demo` kit; grouped into soft/hard layers with round-robin takes. Tom 2 is a DERIVED (transposed rack-tom) sample. The WAVs under `samples/acoustic/` are git-ignored; build or verify them with `python scripts/fetch_acoustic_samples.py` (`--verify` is offline). Source, hashes and the licence notice: `samples/LICENSES.md`.
- `samples/manifest.json` — deterministic SYNTHETIC WAV test fixtures generated by `scripts/generate_sample_bank.py`; never output-latency or real-world evidence.
- `samples/LICENSES.md` — source, licence, access date, and the strict runtime-recorded/test-synthetic distinction.
