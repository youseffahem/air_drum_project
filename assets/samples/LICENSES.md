# Phase 04 local sample licences

## Runtime bank — prerecorded Roland TR-505 samples

The runtime candidate bank uses seven WAV recordings from the
[Oramics Sampled TR-505 collection](https://oramics.github.io/sampled/DM/TR-505/), whose metadata
labels the collection **Public Domain** and links each source WAV. Exact local paths and SHA-256
hashes are pinned in `recorded-manifest.json`; files are stored unchanged under `recorded/`.
Accessed 2026-09-21. Runtime playback loads these local files; it does not synthesize drum sounds.

## Synthetic test bank

The other WAV files in this directory are deterministic procedural sound-design assets generated by
`scripts/generate_sample_bank.py`. They are not recordings, participant data, physical ground
truth, or real-world validation evidence.

The project dedicates these generated WAV assets to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The generating source code remains
under the repository's project licence. Their hashes and provenance are in `manifest.json` and they
remain test fixtures only.
